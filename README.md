# BMW Ride Planner

A ride planner built for motorcyclists, not for commuters.

Most routing software answers "what is the fastest way from A to B?" That is the
wrong question for a rider on a Sunday morning. This project answers a different
one: **what is the best ride I can have today?** — sweeping corners, elevation,
good tarmac, a view worth stopping for, a coffee stop at the right moment.

Built for the **BMW Motorrad track** at the TUM.ai EHL Zurich hackathon.
